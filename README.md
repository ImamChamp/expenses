# Учёт расходов

Простое консольное приложение для учёта личных трат. Записываешь название и сумму каждой траты, смотришь список и общую сумму.

## Возможности

- добавить трату (название и сумма, дата ставится автоматически);
- показать все траты с номерами и датами;
- посчитать общую сумму всех трат;
- изменить название или сумму траты (Enter оставляет старое значение);
- удалить трату с подтверждением;
- показать траты за период и их итог;
- экспортировать все траты в `expenses.csv`, который открывается в Excel;
- траты сохраняются в файл `expenses.json`, поэтому не пропадают после закрытия программы.

## Требования

- Python 3.6 или новее (библиотеки сторонние не нужны).

## Запуск

```bash
python expenses.py
```

В меню введите номер нужного действия и нажмите Enter.
