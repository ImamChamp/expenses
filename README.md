# Учёт расходов

Простое консольное приложение для учёта личных трат. Записываешь название и сумму каждой траты, смотришь список и общую сумму.

## Возможности

- добавить трату (название и сумма);
- показать все траты с номерами;
- посчитать общую сумму всех трат;
- траты сохраняются в файл `expenses.json`, поэтому не пропадают после закрытия программы.

## Требования

- Python 3.6 или новее (библиотеки сторонние не нужны).

## Запуск

```bash
python expenses.py
```

В меню введите номер нужного действия и нажмите Enter.
